# Jawaban
Event Delegation adalah sebuah teknik dalam JavaScript yang memanfaatkan mekanisme event bubbling untuk menangani event dari banyak elemen melalui satu event listener yang dipasang pada elemen induknya (parent element). Dengan kata lain,
daripada memasang event listener pada setiap elemen anak satu per satu, kita cukup memasangnya pada parent, lalu menentukan elemen mana yang sebenarnya memicu event tersebut.
Konsep Dasar

Ketika sebuah event terjadi pada suatu elemen, misalnya tombol diklik, event tersebut tidak berhenti pada elemen itu saja. Event akan bergerak naik ke elemen induknya, lalu ke induk berikutnya, hingga mencapai objek document. Proses ini disebut event bubbling.

Contoh:

```javascript
document.getElementById("container").addEventListener("click", (event) => {
  if (event.target.tagName === "BUTTON") {
    console.log("Tombol diklik");
  }
});
```

Pada contoh tersebut, satu event listener pada `container` dapat menangani klik dari semua tombol yang ada di dalamnya.
